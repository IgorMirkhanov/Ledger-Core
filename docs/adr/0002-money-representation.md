# ADR-0002: Деньги в int64 минорных единиц

**Статус:** принято

## Решение
- Сумма: `int64` в минорных единицах валюты; экспонента из справочника `currencies`.
- В БД: `BIGINT`. В gRPC: `int64`. В REST JSON: **строка** (`"10050"`), т.к. JS Number теряет точность > 2^53.
- FX-курс: `NUMERIC(20,10)` / `*big.Rat`, округление half-even один раз, при расчёте dest_amount.
- `float32/float64` для денег запрещены (правило в `.cursor/rules`).

## Альтернативы
- `decimal` (shopspring) везде: удобно, но медленнее и провоцирует дробные копейки.
- `NUMERIC` в БД для балансов: корректно, но int64 проще, быстрее и достаточно (9.2e18 минорных единиц).

## Последствия
+ Нет ошибок округления, арифметика O(1), проверка переполнения явная (`money.AddInt64`).
− Валюты с экспонентой > 4 не поддерживаются (не нужны).
